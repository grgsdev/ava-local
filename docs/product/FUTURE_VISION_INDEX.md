# Índice da Visão Futura

O Documento 05 é visão futura. Não faz parte da prioridade atual, não autoriza implementação e deve apenas orientar decisões que evitem bloqueios de evolução.

Itens futuros identificados: ADM Master; Manager independente; Cliente Final; usuários subordinados; múltiplas empresas avançadas; cobrança; créditos; gateways; LMS completo; webhooks; domínios avançados; relatórios financeiros; notificações avançadas; auditoria ampliada; múltiplas moedas; arquitetura distribuída ou microserviços.

Nenhum item deste índice deve ser tratado como requisito concluído, escopo de deploy ou decisão de arquitetura atual.
