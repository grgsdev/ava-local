# Produto AVAMovie

O AVAMovie é uma plataforma de projetos audiovisuais interativos. O Documento 04 define o MVP obrigatório atual; o Documento 05 descreve evolução futura e não autoriza implementação nesta etapa.

## Perfis prioritários do MVP

- Master;
- ADM Cliente PJ;
- Editor.

## Domínios

Empresas e usuários, vínculos e permissões; projetos e vídeos; interações; editor e player; aprovação; publicação; URLs seguras; relatórios; notificações; histórico; logs; segurança e isolamento.

Este arquivo é índice, não especificação completa. Consulte o [índice de requisitos do MVP](MVP_REQUIREMENTS_INDEX.md) e o [índice da visão futura](FUTURE_VISION_INDEX.md).
