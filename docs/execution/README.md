# Execução por Unidades

O processo canônico é:

1. o chat define a unidade;
2. o chat produz um prompt único;
3. o Codex executa somente o autorizado;
4. o Codex produz relatório e evidências;
5. o usuário retorna os resultados;
6. o chat aprova, corrige, bloqueia ou prepara a próxima unidade.

Regras: uma unidade por vez; sem ampliação de escopo; sem autorização presumida; sem declarar conclusão sem evidência; sem depender exclusivamente de `/tmp`; sem modificar AWS, Git remoto ou deploy sem autorização.
